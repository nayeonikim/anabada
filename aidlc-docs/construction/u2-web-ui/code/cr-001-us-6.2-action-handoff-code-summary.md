## 확정된 열린 결정 (반영)
- **Q-TARGET**: `targetAssetNames` 표시, `length === 0`이면 숨김.
- **Q-NULL**: `actionHandoff == null`에도 `✨ 추천 프롬프트` 탭 유지, 패널 안 부재 안내. 판정·후보·근거 독립 유지(비차단).
- **Q-LABEL**: 탭 제목 `✨ 추천 프롬프트` 통일 / 내부 박스 라벨 "추천 프롬프트" / NEEDS_REVIEW는 "판단 확정을 위한 검토용 프롬프트…" 명시 / 개발 실행 유도(명령형 CTA) 문구 없음.
- **Q-TEST**: 신규 테스트 하네스 없음 — `tsc(strict) + vite build` + 스모크(Decision 4종·Copy 성공/실패·null·모바일·키보드).
