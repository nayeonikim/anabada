# UI 디자인 비교 분석: 목표 목업(Anabada) vs. 현재 구현

**작성일**: 2026-09-09
**대상**: `frontend/` (React 18 + TypeScript + Vite)
**목적**: 원하는 목업(Anabada 검색형 UI)과 현재 구현(Rebuild or Reuse Advisor 대시보드)의 갭 분석

> ⚠️ 본 문서는 **분석 결과 기록 전용**입니다. 실제 구현 변경은 포함하지 않습니다.

## 2. 현재 구현 개요

- **기술 스택**: React 18 + TypeScript + Vite, CSS 프레임워크 없음. 단일 전역 CSS(`src/styles.css`)에 CSS 커스텀 프로퍼티(디자인 토큰) 사용.
- **화면**: 단일 화면(라우팅 없음). 헤더 + 3-컬럼 그리드(`380px 1fr 380px`, 1100px 이하에서 1열).
  - 좌: `IntentPanel` (요청 입력·의도 구조화)
  - 중: `RankingPanel` + `FeedbackBar` (후보 랭킹·종합 권고·피드백)
  - 우: `EvidencePanel` (근거 체인)
- **테마**: 다크. 배경 `#0f1420`, 표면 `#171d2b`, 텍스트 `#e7ecf5`, 강조 `#4f8cff`.
- **결정 색상**: REUSE=초록 `#2ecc8f`, EXTEND=파랑 `#4f8cff`, NEEDS REVIEW=앰버 `#f5a623`, DEVELOP=보라 `#b06cff`.
- **워크플로우(백엔드 3콜)**: `/intent` → 구조화된 의도 편집 → `/advise` → 랭킹·결정·근거 → `/feedback`.
- **점수 표현**: 재사용성 점수를 퍼센트 텍스트로만 표시(그래픽 게이지/프로그레스 없음).
- **접근성**: `:focus-visible`, `role`/`aria-*` 등 이미 잘 구현됨.

## 3. 목표 목업 개요

- **화면 1 — 검색 홈**: "무엇을 찾고 계신가요?" 대형 제목 + 중앙 검색바(둥근 pill) + 예시 질문 칩 3개 + 좌하단 그라데이션 장식 + 푸터 "Your Knowledge, Smarter with AI."
- **화면 2 — 검색 결과** (세로 흐름):
  1. 뒤로가기 "새 질문하기" + 내 질문 텍스트 + 타임스탬프
  2. AI 진행 스텝바 (질문 이해 → 자료 탐색 → 후보 분석 → 판단 생성, 90%) + "Confluence, JIRA… 분석 중" 설명
  3. 최종 판정 배너 (원형 체크 + REUSE 대형 텍스트 + "기존 자산 재사용 추천" 태그 + AI 요약 답변 박스)
  4. 추천 후보 Top 5 (순위 + 이름 + 메타 + 배지 + 퍼센트 + 펼침)
  5. 후보 상세 탭 3개 (판단 근거 / 적합도 분석 / 참고 자료)

## 4. 항목별 비교

### 4.1 테마 & 색상 — 완전 반전 필요
- 현재: 다크 배경 + 밝은 글씨 → 목업: 라이트 배경 + 파스텔 그라데이션 + 부드러운 그림자.
- ✅ **판정 색상 팔레트는 호환**: REUSE=초록, EXTEND=파랑, NEEDS REVIEW=노랑/앰버, DEVELOP=보라 → 양쪽 동일. CSS 토큰만 라이트 톤으로 재조정하면 됨.

### 4.2 화면 구조 — 가장 큰 갭
- 현재: 3-컬럼 대시보드(모든 정보 동시 표시).
- 목업: 검색엔진형 2단계 흐름(홈 → 결과, 세로 스크롤).
- 👉 **랜딩 페이지 신규 제작** + **결과의 세로 단일 흐름 재배치** + **화면 전환(라우팅/상태)** 필요.

### 4.3 AI 진행 인디케이터 — 신규 필요
- 현재: 텍스트 "분석 중…"만.
- 목업: 4단계 스텝바 + 진행률(%) + 데이터 소스 설명.
- 👉 스텝 프로그레스 컴포넌트 신규.

### 4.4 최종 판정 배너 — 강화 필요
- 현재: 작은 `.overall` 배너(라벨 + 배지 + 설명).
- 목업: 대형 원형 체크 아이콘 + "REUSE" 대형 텍스트 + 태그 + AI 요약 답변 박스.
- 👉 시각적으로 크게 재디자인.

### 4.5 후보 리스트 — 거의 호환 ✅
- 현재: `.card`에 랭크칩 `#N` + 이름 + 배지 + "재사용성 87%" + 소스칩.
- 목업: "추천 후보 Top 5", 순위 + 이름 + 메타 + 배지 + 퍼센트 + 펼침(∨).
- 👉 구조 유사. 스타일만 라이트 테마로 조정.

### 4.6 상세 근거 — 탭 UI로 재구성
- 현재: 별도 우측 컬럼(`EvidencePanel`)에 근거 리스트.
- 목업: 카드 펼침 시 탭 3개(판단 근거 / 적합도 분석 / 참고 자료).
- 👉 별도 컬럼 → 카드 내부 인라인 탭으로 이동.

### 4.7 브랜딩 & 카피
- 이름 변경: `Rebuild or Reuse Advisor` → **`Anabada`**.
- 푸터 태그라인 추가: "Your Knowledge, Smarter with AI."

## 5. 재사용 가능 vs. 신규 필요

### ✅ 그대로 재사용 가능
- 판정 배지 색상 시스템(초/파/노/보) 및 `badges.ts` 매핑 로직
- 후보 카드의 데이터 구조 및 랭킹 로직
- 백엔드 API 흐름 (`/intent` → `/advise` → `/feedback`)
- 접근성 처리 (`:focus-visible`, `aria-*`)

### 🔨 신규 제작 필요
1. 라이트 테마 전체 재설계 (CSS 토큰 반전)
2. 홈/랜딩 화면 (검색 중심, 예시 질문 칩)
3. 2단계 화면 전환 (홈 ↔ 결과)
4. AI 진행 스텝바 컴포넌트
5. 대형 판정 배너 + AI 요약 박스
6. 카드 내 탭 UI (근거 / 분석 / 참고자료)

---

## 6. 결론

- **데이터·로직·색상 팔레트는 상당 부분 재사용 가능**.
- **화면 구조(3컬럼 대시보드 → 2단계 세로 흐름)와 테마(다크 → 라이트)는 큰 폭의 재작업** 필요.
- 참고: 목업의 검색형 흐름은 `/intent`의 "구조화된 의도 수동 편집" 단계를 UI에서 노출하지 않음. 구현 시 해당 단계를 자동화하거나 재배치하는 UX 결정이 필요함(현재 기능 손실 여부 검토 대상).
